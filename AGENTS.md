# Preferências do usuário

- Após concluir cada alteração ou conjunto coerente de alterações, apresentar
  um resumo breve e perguntar se o usuário deseja criar um commit.
- Aguardar autorização explícita antes de criar o commit. Não interpretar
  pedidos de alteração, testes ou compilação como autorização para commitar.
- Se o usuário não aprovar o commit, manter as alterações locais para revisão.
